Whatever era you fly

The shared sortie

Keep this common range flow in every week’s rotation.

01 / Prepare

  1. Add waypoints before departure
  2. Complete cold start
  3. Taxi and ATC communications
  4. Basic formation (finger‑four / echelon / route)

02 / Work the range

  1. Navigation to the range
  2. Entry into the pattern
  3. Ground attack (CCIP / CCRP / Rockets / Guns)
  4. Package escort
  5. Exit from the range pattern

03 / Recover

  1. Rejoin at the holding point
  2. Holding and separation
  3. Navigation back to base
  4. Landing pattern (CASE I / standard)
  5. Comms and brevities throughout the exercise
