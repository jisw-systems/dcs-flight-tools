## Review Notes

- `Max range` contains mixed values: numeric ranges, `AWACS`, `BOMBER`, and `HELO`.
- The workbook includes repeated RWR codes for different units or systems.
- The source contains apparent spelling variants such as `Covette`, which has been preserved here for review rather than silently corrected.
- This Markdown is an intermediate adaptation; it is not yet connected to the web page.
